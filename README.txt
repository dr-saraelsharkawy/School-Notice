ملفات موقع مدرسة الشهيد أشرف يحي أبو النصر

محتويات الحزمة:
- index.html
- style.css
- script.js

مهم قبل الرفع:
1) ضع ملفي الصورة الأصليين في المجلد نفسه بجوار index.html:
   - logo.JPG
   - Ah.JPG
   يجب أن تكون أسماء الملفات مطابقة تمامًا، بما في ذلك الأحرف الكبيرة والصغيرة.
2) ملفا الصور غير مرفقين بهذه الحزمة لأن الصور الأصلية لم تُرفع في المحادثة.
3) بعد وضع الصور، ارفع الملفات الخمسة معًا إلى مستودع GitHub ثم فعّل GitHub Pages.

تنبيه خصوصية:
GitHub Pages ينشر الموقع للعامة، ولا يوفر تسجيل دخول أو صلاحيات وصول خاصة بمجرد جعل المستودع Public.
لا تنشر بيانات أو صورة طالب قاصر على صفحة عامة إلا بعد التأكد من وجود تفويض وموافقة مناسبة وسياسة نشر معتمدة لدى المدرسة.
زر «تم الاستلام» في هذا النموذج ينفذ عودة إلى الصفحة الرئيسية فقط؛ ولا يسجل اسم المستلم أو وقت الاستلام ولا يرسل إشعارًا للإدارة.
